# Security Operations Console

Панель мониторинга сетевой телеметрии, задержек API и инцидентов безопасности в распределенной инфраструктуре.

Онлайн-демо: https://lelyaler.github.io/Security-Operations/

### О проекте

Интерфейс дежурного инженера для быстрой оценки состояния сетевых шлюзов и расследования аномалий. Включает графики объемов трафика с фильтрацией по временным окнам, перцентили времени отклика шлюзов (p50, p95, p99), распределение HTTP-статусов и журнал событий с инспектором сырых данных.

Состояние расследования и фильтры сохраняются в URL через нативный хеш-роутинг и дублируются в localStorage. Реализована синхронизация с публичным фидом известных эксплойтов CISA KEV, а также экспорт записей в CSV и JSON для выгрузки отчетов.

### Стек

React 19, TypeScript, Vite, Recharts, Lucide Icons, Vitest, Oxlint.
