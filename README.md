# SecureNode SOC

> **Live Demo:** [https://lelyaler.github.io/Security-Operations/](https://lelyaler.github.io/Security-Operations/)

Аналитический дашборд кибербезопасности для мониторинга сетевого трафика, состояния серверной инфраструктуры, журналов аудита доступа и обработки инцидентов.

## Основные возможности

- **Операционная консоль (SOC)**: мониторинг ключевых метрик (сетевые пакеты, заблокированные угрозы, активные сокет-соединения), живой поток сетевых запросов и графики трафика на Recharts.
- **Матрица серверной инфраструктуры**: мониторинг состояния микросервисов, баз данных и шлюзов с отображением нагрузки на CPU, активных потоков и объёма переданных данных.
- **Центр реагирования на угрозы (IDS)**: изоляция вредоносных IP-адресов, расследование инцидентов по уровням риска и аудит сигнатур атак.
- **Журнал аудита доступа**: реестр системных действий (File Write, SSH Access, API Call) с фильтрацией по типу и статусу, полнотекстовым поиском и экспортом в CSV.
- **Simulation Deck**: панель управления симуляцией атак (эмуляция DDoS, запуск эксплойтов, генерация инцидентов и управление потоком трафика).
