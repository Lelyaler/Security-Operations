# Edge Gateway & Security Telemetry Console

Интерфейс мониторинга распределенных API-шлюзов, сетевой телеметрии и аудита правил блокировки трафика.

[**Открыть Live Demo**](https://lelyaler.github.io/Security-Operations/)

---

## О проекте и мотивация

Проект разработан как pet-project для исследования архитектурных подходов к рендерингу потоковых телеметрических данных на фронтенде с высокой частотой обновления, строгой типизацией на TypeScript и бескомпромиссной оптимизацией Core Web Vitals.

Основная задача — создать интерфейс наблюдаемости (observability), приближенный по эргономике к панелям Cloudflare, Datadog и AWS API Gateway, без использования тяжелых готовых UI-китов (MUI, Ant Design), опираясь на кастомную дизайн-систему на чистом CSS.

### Ключевые технические задачи:

1. **Оптимизация критического пути рендеринга (Performance 95+)**:
   - Асинхронная неблокирующая загрузка веб-шрифтов через `rel="preload"` и `media="print"`.
   - Внедрение статического inline-каркаса в HTML-шаблон для достижения FCP < 200 мс и предотвращения сдвига макета (CLS = 0).
   - Вынесение тяжелого пакета визуализации (`recharts` + `d3`) в отложенный асинхронный чанк (`React.lazy` + `Suspense` + фильтрация `modulePreload`), что снизило критический JS-бандл с 620 КБ до ~67 КБ (gzip).

2. **Работа с высокочастотным потоком данных (Telemetry Stream)**:
   - Реализация кольцевого буфера фиксированной длины (FIFO) для предотвращения утечек памяти при длительных сессиях мониторинга.
   - Независимый генератор телеметрии с реалистичной вариативностью задержек, динамическим расчетом джиттера и распределением HTTP-статусов (200 / 304 / 429 / 504).
   - Поддержка паузы, очистки и фильтрации трафика в реальном времени.

3. **Синхронизация состояния и экспорт**:
   - Сохранение активных фильтров, поискового запроса и открытого инцидента в URL-параметрах для удобства обмена ссылками между инженерами.
   - Клиентская генерация дампов аудита в форматах CSV и JSON через Blob API.
   - Синхронизация внешних индикаторов аномалий с публичным каталогом CISA KEV с сохранением локальных оверрайдов в localStorage.

## Архитектура проекта

```text
src/
├── components/
│   ├── charts/            # Модульные графики на Recharts с единой темой токенов
│   │   ├── LatencyChart.tsx
│   │   ├── ProtocolChart.tsx
│   │   ├── StatusCodesChart.tsx
│   │   ├── TrafficChart.tsx
│   │   └── chartTheme.ts
│   ├── dashboard/         # Компоненты основного экрана
│   │   ├── KpiGrid.tsx
│   │   └── LiveFeedTable.tsx
│   ├── incidents/         # Журнал инцидентов, фильтры, пагинатор и инспектор
│   │   ├── IncidentFilters.tsx
│   │   ├── IncidentInspector.tsx
│   │   ├── IncidentMetricsCards.tsx
│   │   ├── IncidentPagination.tsx
│   │   └── IncidentTable.tsx
│   ├── Header.tsx         # Шапка с профилем и переключателями
│   ├── Panel.tsx          # Базовый контейнер с заголовком и слотами действий
│   ├── SettingsModal.tsx  # Настройки оператора, частоты опроса и экспорт
│   └── Sidebar.tsx        # Боковая навигация с авто-сворачиванием
├── context/               # Контекст настроек оператора и формата времени
├── hooks/                 # Кастомные хуки (useLiveFeed, useIncidents, useNavigationState)
├── services/              # Клиенты сетевого API и внешней аналитики
├── styles/                # Модульный CSS с дизайн-токенами
├── types/                 # Строгие контракты данных
└── utils/                 # Хелперы форматирования, тесты и генераторы
```

## Стек технологий

* **Фреймворк:** React 19
* **Язык:** TypeScript (strict mode, без `any`)
* **Сборка:** Vite
* **Графика и визуализация:** Recharts, Lucide Icons
* **Тестирование:** Vitest
* **Линтинг:** Oxlint

## Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/Lelyaler/Security-Operations.git
cd Security-Operations

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Запуск тестов
npm test

# Сборка production-бандла
npm run build
```
